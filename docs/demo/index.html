Provalo sul tuo computer

Su Debian/Ubuntu, con curl e i certificati HTTPS disponibili, configura la sorgente una volta:

curl -fsSL https://dev-seq-67.github.io/67/configure-apt.sh -o /tmp/67-configure-apt.sh
sudo sh /tmp/67-configure-apt.sh https://dev-seq-67.github.io/67
sudo apt update

Poi installa il pacchetto e avvia il gatto:

sudo apt install 67
67

Il repository del progetto deve essere configurato prima di usare sudo apt install 67. Per requisiti, alternative e rimozione, leggi il tutorial completo.

Cosa stai guardando

  1. Un contenitore Ubuntu 24.04 parte senza il pacchetto 67. Sono già presenti curl, certificati HTTPS e sudo.
  2. APT scarica il pacchetto dal repository HTTPS del progetto e installa Chafa e Zsh dalle sorgenti Ubuntu.
  3. Il comando 67 apre la sessione temporanea. Chafa rende la GIF a 48 colonne × 8 righe; Zsh gestisce l'input sottostante.
  4. La prova printf produce davvero il suo output. Stop, riavvio e uscita completano la dimostrazione.

67 1.5.0 · Chafa 1.14.0 · Zsh 5.9. In questo contenitore sudo non chiede la password. Il tuo computer può richiederla. La cattura dura 75 secondi, a velocità reale.
